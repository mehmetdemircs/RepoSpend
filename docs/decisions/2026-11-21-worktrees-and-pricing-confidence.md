# Worktree grouping and pricing confidence

Git worktrees let agents run in parallel but a checkout path alone splits one repository’s totals. Resolve Git’s common directory when it identifies the main checkout and keep the worktree path on each session. The repository remains the grouping key and users can filter its sessions by checkout.

Local usage and billing metadata vary across client versions. Keep versioned API-equivalent rate cards and local overrides, and disclose when the requested model was priced using another card. For Codex, prefer explicit request deltas when cumulative-only checkpoints coexist. Deduplicate response records by response ID and pair their legacy token-count events by request and thread totals. A checkpoint that cannot be matched to request detail lowers token confidence and surfaces a coverage warning.
